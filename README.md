# Rental Document Review Assistant

A document-completeness agent for rental application packages, with mandatory human housing decisions.

## Workflow

1. Load the approved document checklist.
2. Check submitted files for presence and readability.
3. Flag missing, expired, or inconsistent items.
4. Route the report to an authorized reviewer.

## Passport Files

The root folder contains `agent.yaml`, `SOUL.md`, and `EXPLAINABILITY.md`.
